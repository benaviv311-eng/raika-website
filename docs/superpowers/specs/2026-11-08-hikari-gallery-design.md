# Hikari's Approved Combat Gallery

**Intent:** Make Hikari's four approved action and defense renders accessible from her existing character profile in the Raika website, on desktop and mobile.

**Scope:** Reuse the existing four-thumbnail profile gallery. Add the four assets under `character-variants/` and attach them to both Hikari's family and guard profiles. Keep all portraits, characters, navigation, layout and character canon unchanged.

**Approaches:** Reuse the existing profile gallery (chosen; smallest coherent update); create a separate Hikari page (rejected as redundant); build a new custom viewer (rejected as unnecessary).

**Visual order:** Rope Dart Throw, Overhead Rope Spin, Dual Daggers, Crossed Dagger Defense.

**Acceptance:** Both Hikari profile entries have exactly four matching variants; each image is a valid locally present asset; the existing character-gallery tests continue to pass.
